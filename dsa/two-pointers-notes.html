Two Pointers

A movement strategy, not a data structure. Two variables track positions inside a sequence; their coordinated movement eliminates candidate pairs without reexamining them.

Prev: Hash Maps
Next: Sliding Window
Problems: 12 covered
Patterns: 6 shapes

§1 — First Principles

The core insight: brute force on sequences is O(n²) because it considers every pair. Two pointers achieve O(n) by maintaining an elimination argument — every pointer move discards an entire row or column of candidate pairs that cannot possibly be the answer.

The Treasure-Hunt Analogy "If I say find treasure anywhere, you're lost. If I say the treasure is green, you immediately know what to look for." Two Pointers give you that starting narrowing — two fixed limits. The only legal moves shrink the space. You are guaranteed to cover all possibilities in one pass.

What it is

Two index variables that move through a sequence (array, string, linked list) in a coordinated way. Movement rules are chosen so no pointer ever moves backward — giving amortized O(n).

Why it works

Each move discards candidates the array's ordering tells us cannot be the answer. You exploit sortedness (or a structural property) to skip the work a nested loop would do.

Core requirement

A monotone decision: "if my current pair fails in direction X, no pair with the same left but a further-left right could succeed." Without monotonicity two pointers may miss answers.

§2 — Python Mechanics

Idiomatic Python patterns

left, right = 0, len(arr) - 1       # initialise both

    if condition: left  += 1
    else:         right -= 1

# Skip duplicates (after recording result)

while left < right and arr[right] == arr[right - 1]: right -= 1

The 6 Two-Pointer Shapes

Every two-pointer problem fits one of these shapes. Recognising the shape immediately gives you the pointer initialisation and the termination condition.

Pattern 1Sorted array required

Converging (Opposite Ends)

Start left = 0, right = n−1. Advance the pointer whose side gives you a strictly better chance of satisfying the condition. Stop when they cross.

Elimination argument: if arr[left]+arr[right] < target, every pair using arr[left] with a smaller right value also fails — so advance left.

Problems: Two Sum II, Container With Most Water, Valid Palindrome, Reverse String, reverse a section, partition 0s&1s

left, right = 0, len(arr) - 1
while left < right:
    if check(arr[left], arr[right]):  # found
        ...
    elif need_bigger:
        left  += 1
    else:
        right -= 1
Pattern 2In-place write

Read / Write (Same Direction)

write trails read. read sweeps every element; write advances only when the element deserves to stay. Invariant: arr[0..write-1] is always the filtered result.

Problems: Remove Duplicates, Remove Element, Move Zeros

write = 0
for read in range(len(arr)):
    if keep(arr[read]):
        arr[write] = arr[read]
        write += 1
Pattern 3Two sorted sequences

Two Sequences (One Pointer Each)

i walks array A, j walks array B. Compare A[i] vs B[j]; advance the pointer pointing at the smaller (or equal) value.

Problems: Merge Two Sorted Arrays, Union, Intersection

i = j = 0
while i < len(a) and j < len(b):
    if a[i] <= b[j]:
        process(a[i]); i += 1
    else:
        process(b[j]); j += 1
# drain whichever list is non-empty
Pattern 4Sort first

Sort + Anchor + Converge (k-Sum)

Sort the array. Fix k−2 anchors with outer loops. Run a converging two-pointer pass on the remaining subarray. Skip duplicates at every level to avoid duplicate triplets/quadruplets.

Time: O(nᵏ⁻¹) — sort is dominated by the outer loops.

Problems: 3Sum, 4Sum, k-Sum

nums.sort()
for i in range(n - 2):
    if i > 0 and nums[i] == nums[i-1]: continue  # skip dup anchor
    left, right = i+1, n-1
    while left < right:
        total = nums[i] + nums[left] + nums[right]
        if   total == 0: record(); skip_dups(); advance()
        elif total <  0: left  += 1
        else:            right -= 1
Pattern 5Greedy side choice

Move the Limiting Side (Greedy)

Area / capacity is limited by the shorter side. Moving the longer side can only decrease width; only moving the shorter side can possibly increase height enough to compensate.

Problems: Container With Most Water

left, right = 0, n - 1
best = 0
while left < right:
    best = max(best, min(h[left], h[right]) * (right - left))
    if h[left] < h[right]: left  += 1
    else:                   right -= 1
Pattern 63 partitions, 1 pass

Dutch National Flag (3-Way Partition)

Three regions: [0..low−1] all 0s, [low..mid−1] all 1s, [high+1..n−1] all 2s. mid is the exploration frontier. Crucially, when you swap mid with high, you don't advance mid — you don't yet know what came back from the right.

low = mid = 0
high = n - 1
while mid <= high:
    if   nums[mid] == 0: swap(low,mid);  low++;  mid++
    elif nums[mid] == 1:                         mid++
    else:                swap(mid,high); high--  # NOT mid++
BonusLinked list

Slow / Fast (Floyd's Tortoise & Hare)

Both start at head. Slow moves 1 step; Fast moves 2 steps. Because Fast covers twice the distance, Slow is always at the halfway point when Fast reaches the end. In a cycle, Fast "laps" Slow — they are guaranteed to meet because in a closed loop a faster runner always catches the slower one.

slow = fast = head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
    if slow is fast: return True  # cycle detected
# If no cycle: slow is the middle node

1
Two Sum II
Given a sorted array and a target, return 1-indexed pair that sums to target.
ConvergingLeetCode 167
Brute-Force Algorithm
  1. For every pair (i, j) with i < j, check if nums[i] + nums[j] == target.
  2. Return [i+1, j+1] on the first match.
Two-Pointer Algorithm
  1. Place left at index 0, right at index n−1.
  2. Compute sum = nums[left] + nums[right].
  3. If sum == target → return [left+1, right+1].
  4. If sum < target → advance left (need bigger left value).
  5. If sum > target → retreat right (need smaller right value).
  6. Repeat until left ≥ right.
def two_sum_brute(nums, target):          # O(n²) time, O(1) space
    n = len(nums)
    for i in range(n):
        for j in range(i + 1, n):
            if nums[i] + nums[j] == target:
                return [i + 1, j + 1]
    return []
public static int[] twoSumBrute(int[] nums, int target) {
    for (int i = 0; i < nums.length; i++)
        for (int j = i + 1; j < nums.length; j++)
            if (nums[i] + nums[j] == target)
                return new int[]{i + 1, j + 1};
    return new int[]{};
}
def two_sum(nums, target):               # O(n) time, O(1) space
    left, right = 0, len(nums) - 1
    while left < right:
        s = nums[left] + nums[right]
        if   s == target: return [left + 1, right + 1]
        elif s <  target: left  += 1
        else:             right -= 1
    return []
public static int[] twoSum(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left < right) {
        int s = nums[left] + nums[right];
        if      (s == target) return new int[]{left+1, right+1};
        else if (s <  target) left++;
        else                  right--;
    }
    return new int[]{};
}

3Sum
Find all unique triplets that sum to zero.
Sort + Anchor + ConvergeLeetCode 15
Two-Pointer Algorithm
  1. Sort the array.
  2. For each anchor index i (skip duplicates):
  3.   Run converging two-pointer on nums[i+1..n−1] looking for sum = −nums[i].
  4.   When a triplet is found, record it, then skip all duplicate left and right values before advancing both pointers.
def three_sum(nums):                      # O(n²) time, O(n) for sort
    nums.sort()
    result, n = [], len(nums)
    for i in range(n - 2):
        if i > 0 and nums[i] == nums[i-1]: continue
        left, right = i + 1, n - 1
        while left < right:
            total = nums[i] + nums[left] + nums[right]
            if total == 0:
                result.append([nums[i], nums[left], nums[right]])
                while left < right and nums[left]  == nums[left+1]:  left  += 1
                while left < right and nums[right] == nums[right-1]: right -= 1
                left += 1; right -= 1
            elif total < 0: left  += 1
            else:           right -= 1
    return result
public static List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> result = new ArrayList<>();
    int n = nums.length;
    for (int i = 0; i < n - 2; i++) {
        if (i > 0 && nums[i] == nums[i-1]) continue;
        int left = i+1, right = n-1;
        while (left < right) {
            int total = nums[i] + nums[left] + nums[right];
            if (total == 0) {
                result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                while (left < right && nums[left]  == nums[left+1])  left++;
                while (left < right && nums[right] == nums[right-1]) right--;
                left++; right--;
            } else if (total < 0) left++;
              else                right--;
        }
    }
    return result;
}

Merge Two Sorted Arrays
Produce a single sorted array from two sorted inputs.
Two Sequences
Two-Pointer Algorithm
  1. i=0, j=0. Compare A[i] vs B[j]; append the smaller, advance its pointer.
  2. When one array is exhausted, append the rest of the other.
def merge_sorted(a, b):                   # O(m+n) time, O(m+n) space
    result = []
    i = j = 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]: result.append(a[i]); i += 1
        else:            result.append(b[j]); j += 1
    result.extend(a[i:]); result.extend(b[j:])
    return result
public static int[] mergeSorted(int[] a, int[] b) {
    int[] res = new int[a.length + b.length];
    int i = 0, j = 0, k = 0;
    while (i < a.length && j < b.length)
        res[k++] = (a[i] <= b[j]) ? a[i++] : b[j++];
    while (i < a.length) res[k++] = a[i++];
    while (j < b.length) res[k++] = b[j++];
    return res;
}

Union of Two Sorted Arrays
Merge without duplicates.
Two Sequences
def union(a, b):
    result = []
    i = j = 0
    while i < len(a) and j < len(b):
        if   a[i] < b[j]: val = a[i]; i += 1
        elif b[j] < a[i]: val = b[j]; j += 1
        else:             val = a[i]; i += 1; j += 1
        if not result or result[-1] != val: result.append(val)
    for arr in (a[i:], b[j:]):
        for val in arr:
            if not result or result[-1] != val: result.append(val)
    return result
public static List<Integer> union(int[] a, int[] b) {
    List<Integer> res = new ArrayList<>();
    int i = 0, j = 0;
    while (i < a.length && j < b.length) {
        int val;
        if      (a[i] < b[j])  val = a[i++];
        else if (b[j] < a[i])  val = b[j++];
        else                  { val = a[i++]; j++; }
        if (res.isEmpty() || res.get(res.size()-1) != val) res.add(val);
    }
    // drain remaining
    while (i < a.length) { if(res.isEmpty()||res.get(res.size()-1)!=a[i]) res.add(a[i]); i++; }
    while (j < b.length) { if(res.isEmpty()||res.get(res.size()-1)!=b[j]) res.add(b[j]); j++; }
    return res;
}

def intersection(a, b):
    result = []
    i = j = 0
    while i < len(a) and j < len(b):
        if a[i] == b[j]:
            if not result or result[-1] != a[i]: result.append(a[i])
            i += 1; j += 1
        elif a[i] < b[j]: i += 1
        else:             j += 1

public static List<Integer> intersection(int[] a, int[] b) {
    List<Integer> res = new ArrayList<>();
    int i = 0, j = 0;
    while (i < a.length && j < b.length) {
        if (a[i] == b[j]) {
            if (res.isEmpty() || res.get(res.size()-1) != a[i]) res.add(a[i]);
            i++; j++;
        } else if (a[i] < b[j]) i++;
          else                   j++;
    }
    return res;
}

Valid Palindrome
Ignore non-alphanumeric chars; case-insensitive.
ConvergingLeetCode 125
def is_palindrome(s):                     # O(n) time, O(1) space
    left, right = 0, len(s) - 1
    while left < right:
        while left < right and not s[left].isalnum():  left  += 1
        while left < right and not s[right].isalnum(): right -= 1
        if s[left].lower() != s[right].lower(): return False
        left += 1; right -= 1
    return True
public static boolean isPalindrome(String s) {
    int l = 0, r = s.length() - 1;
    while (l < r) {
        while (l < r && !Character.isLetterOrDigit(s.charAt(l))) l++;
        while (l < r && !Character.isLetterOrDigit(s.charAt(r))) r--;
        if (Character.toLowerCase(s.charAt(l)) !=
            Character.toLowerCase(s.charAt(r))) return false;
        l++; r--;
    }
    return true;
}

ConvergingLeetCode 344
def reverse_string(s):                    # O(n) time, O(1) space
    left, right = 0, len(s) - 1
    while left < right:
        s[left], s[right] = s[right], s[left]
        left += 1; right -= 1

def reverse_section(s, lo, hi):           # reverse s[lo..hi] inclusive
    while lo < hi:
        s[lo], s[hi] = s[hi], s[lo]
        lo += 1; hi -= 1
public static void reverseString(char[] s) {
    int l = 0, r = s.length - 1;
    while (l < r) {
        char tmp = s[l]; s[l] = s[r]; s[r] = tmp;
        l++; r--;
    }
}

Middle of Linked List
Return the middle node (second middle for even length).
Slow / FastLeetCode 876
Algorithm
  1. Both pointers start at head.
  2. Slow moves 1 step; Fast moves 2 steps.
  3. When fast.next is null (odd) or fast is null (even), slow is at middle.
  4. Why: Fast covers 2× distance → Slow is always at the halfway mark.
def find_middle(head):                    # O(n) time, O(1) space
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow
public static ListNode findMiddle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;
}

Linked List Cycle (Floyd's)
Detect if a linked list has a cycle.
Slow / FastLeetCode 141
Why they always meet in a cycle Think of a race on a circular track. The fast runner covers 2 steps per tick; the slow runner covers 1. Once fast laps slow, the gap between them shrinks by 1 each tick. Eventually the gap hits 0 — they collide. If there's no cycle, fast falls off the end (reaches null). 
def has_cycle(head):                      # O(n) time, O(1) space
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast: return True
    return False
public static boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}

Sort Colors — Dutch National Flag
Sort array of 0s, 1s, 2s in-place in one pass.
Dutch National FlagLeetCode 75
Critical Bug Trap When swapping nums[mid] with nums[high], do NOT increment mid. You just brought an unknown value from the right side — it still needs classification. 
def sort_colors(nums):                    # O(n) time, O(1) space
    low = mid = 0
    high = len(nums) - 1
    while mid <= high:
        if   nums[mid] == 0:
            nums[low], nums[mid] = nums[mid], nums[low]
            low += 1; mid += 1
        elif nums[mid] == 1:
            mid += 1
        else:                               # 2: swap to high end
            nums[mid], nums[high] = nums[high], nums[mid]
            high -= 1                       # DO NOT mid += 1
public static void sortColors(int[] nums) {
    int low = 0, mid = 0, high = nums.length - 1;
    while (mid <= high) {
        if      (nums[mid] == 0) { swap(nums,low,mid);  low++;  mid++; }
        else if (nums[mid] == 1) {                              mid++; }
        else                     { swap(nums,mid,high); high--;         }
    }
}
private static void swap(int[] a, int i, int j) {
    int tmp = a[i]; a[i] = a[j]; a[j] = tmp;
}

Container With Most Water
Find two lines forming a container with maximum water.
Greedy ConvergingLeetCode 11
Greedy Argument
  1. Area = min(left height, right height) × width.
  2. Moving the taller wall can only decrease or maintain min-height while also shrinking width → guaranteed worse or equal.
  3. Moving the shorter wall might find a taller replacement → the only chance to improve.
  4. Therefore always advance the pointer on the shorter side.
def max_water(height):                    # O(n) time, O(1) space
    left, right = 0, len(height) - 1
    best = 0
    while left < right:
        area = min(height[left], height[right]) * (right - left)
        best = max(best, area)
        if height[left] < height[right]: left  += 1
        else:                            right -= 1
    return best
public static int maxWater(int[] h) {
    int left = 0, right = h.length - 1, best = 0;
    while (left < right) {
        int area = Math.min(h[left], h[right]) * (right - left);
        best = Math.max(best, area);
        if (h[left] < h[right]) left++;
        else                    right--;
    }
    return best;
}

slow = fast = head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
    if slow is fast:        # cycle detection
        return True
# No cycle → slow is at middle node

Common Mistakes & Edge Cases

Bug

Advancing mid after DNF high-swap

In Dutch National Flag, when swapping nums[mid] with nums[high], the value at mid is now unknown — it just arrived from the right. Don't increment mid until it's been classified.

Bug

Off-by-one: left < right vs left <= right

Converging loops use < (stop when they cross). Read/write loops use for read in range(n) (visit every element). Confusing these causes missed elements or infinite loops.

Bug

Forgetting to skip duplicates in k-Sum

In 3Sum, skip duplicates at both the anchor level (i) and both pointer levels after finding a valid triplet. Missing any one of these yields duplicate results.

Bug

Sorting mutates the caller's array

In Python, nums.sort() modifies in-place and returns None. Never write nums = nums.sort() — nums becomes None. Use nums.sort() (mutate) or sorted_nums = sorted(nums) (copy).

Trap

Two pointers on unsorted data

Converging two pointers require a monotone property (usually sortedness). Without it you can't guarantee that advancing the left pointer always increases the sum — the elimination argument breaks.

Trap

Cycle detection: slow is fast not slow == fast

In Python, == checks value equality; is checks object identity. For cycle detection you want the exact same node, so use is. In Java, use == for object reference comparison.

Edge Cases to Always Test

  • Empty input: [], "", None head.
  • Single element: two-pointer loop never enters — return that element or false immediately.
  • All same elements: duplicate-skip logic must handle [0,0,0,0] without infinite loop.
  • Already sorted / reverse sorted: converging still O(n); no worst-case regression.
  • Even vs odd length linked list: middle node is (n/2)th or ((n+1)/2)th depending on your loop guard.
  • Two-element list (cycle): head → node → head; fast.next.next is head; must detect in first iteration.
  • Container water with all equal heights: every pair gives same area; greedy still terminates correctly.
  • Palindrome with all non-alphanumeric chars: both pointers meet without ever comparing — return True.

§12 — Mental Model: The Shrinking Search Space

Core idea: Two pointers work whenever moving a pointer can provably eliminate a set of candidates that cannot contain the answer. Every move shrinks the space; the loop terminates; you never revisit eliminated candidates.

This is why the nested-loop analysis ("looks like O(n²)") is wrong: each pointer only moves forward, so the total number of pointer steps across the entire run is O(n), not O(n) per outer iteration.

Converging — shrinking a window

[ eliminated | L ·candidate space· R | eliminated ]
  ← left advances                right recedes →

The candidate space is all pairs (i,j) with L≤i<j≤R. Every move eliminates one row or one column of that grid.

Read / Write — two roles on one array

[ clean | W ··· R | unprocessed ]
  write ptr          read ptr →

The write pointer is a boundary: everything behind it is already correct. The read pointer scans ahead, deciding whether each element crosses into the clean region.

Dutch National Flag — three regions

[ 0s | 1s | unknown | 2s ]
  0   low  mid      high  n-1

Three invariants maintained simultaneously. The unknown region shrinks until mid>high.

Slow / Fast — distance encodes structure

slow: 1 step/tick  →  finds middle
fast: 2 steps/tick →  detects cycle

The speed ratio encodes structural knowledge: when fast is at the end, slow is exactly at the midpoint.

Amortized O(n) proof (one sentence)
Each pointer starts at one end and moves monotonically toward the other; with two pointers and an array of length n, the total pointer steps across the entire algorithm ≤ 2n, regardless of how many while loops are nested.
