Glossary for the words worth knowing

Hover over a dotted term anywhere in the book. Click it on desktop or mobile to keep the explanation open. These definitions are intentionally practical: enough to understand the system and explain it in an interview without turning the chapter into a textbook.

KV cache

saved attention information from earlier tokens that makes generation faster but consumes GPU memory

latency

how long one request takes from start to finish

throughput

how much work the system completes in a given time

p99

the latency below which 99% of requests finish; a useful way to see tail slowness

FLOPs

the number of floating-point math operations; useful, but not always the thing limiting a real system

memory bandwidth

how quickly data can move between memory and the processor; often a real bottleneck for LLM inference

activation

intermediate values produced during a model forward pass; training often needs to keep them for backpropagation

backpropagation

the training step that sends error information backward through the network to update weights

gradient

information about how changing a parameter would change the training objective

quantization

using fewer bits to represent values, usually to reduce memory and improve speed

ANN

approximate nearest neighbor search; fast similarity search that accepts a small chance of missing the exact best match

embedding

a vector representation that places semantically similar items near each other

reranker

a second model that reorders retrieved results using a more expensive relevance check

hallucination

a model output that is unsupported, invented, or incorrect even when it sounds confident

idempotency

a property where repeating an operation has the same intended effect as doing it once

continuous batching

adding and removing requests from a running inference batch instead of waiting for the whole batch to finish

speculative decoding

using cheap guesses for future tokens and having the main model verify them

prefix caching

reusing computation for a shared beginning of multiple prompts

all-to-all communication

a distributed pattern where devices exchange data with many or all other devices

MoE

Mixture of Experts: a model that routes each token to only a small subset of specialist sub-networks

LoRA

a parameter-efficient fine-tuning method that learns small low-rank updates instead of changing every model weight

QLoRA

LoRA-style fine-tuning while the base model is quantized to reduce memory use

RAG

retrieval-augmented generation: retrieve external evidence and give it to the model while answering

context window

the maximum amount of tokenized information a model can accept in one request

TTFT

time to first token: how long a user waits before generation begins

TPOT

time per output token: how quickly the stream continues after the first token

SLO

service-level objective: a target for reliability or performance that a production system should meet

rollback

reverting a deployed change when it causes problems

distribution shift

when real inputs differ from the data or conditions a model was trained or evaluated on

non-IID

data across users or devices is not identically distributed; each participant may look meaningfully different

checkpoint

a saved model/training state that lets training resume or provides a version to evaluate

beam search

keeping several candidate outputs at each generation step instead of following only one path

verifier

a system that checks whether a candidate answer or step meets some correctness criterion
