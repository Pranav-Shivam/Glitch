# Most-asked sliding window problems

- **Retrieved:** 2026-10-04
- **Question:** Which sliding window problems are most commonly asked at large tech companies, and which curated lists include them?
- **Used for:** `dsa/Sliding_Window_Notes_v2.html` (Part 7 provenance labels, Sources note).
- **Local cache checked first:** `dsa-array-problem-frequency-2026.md` and `dsa-company-interview-calibration-2026.md` had only passing sliding-window mentions (Meta: anagram start indices, sliding window sum/max; Netflix: sliding window; Amazon list includes sliding-window problems). Nothing topic-specific, so a short web check was made.

## Findings

- **NeetCode 150, "Sliding Window" category (6 problems), per crackr.dev and a search summary:** Best Time to Buy and Sell Stock (Easy), Longest Substring Without Repeating Characters (Medium), Longest Repeating Character Replacement (Medium), Permutation in String (Medium), Minimum Window Substring (Hard), Sliding Window Maximum (Hard).
- **Blind 75:** search results confirm Longest Substring Without Repeating Characters, Longest Repeating Character Replacement and Minimum Window Substring are in the Blind 75 (string section). Only a search summary, the list page itself was not fetched.
- **TechScreen article (dated 2026-04-04):** Minimum Window Substring (76) said to appear "across all FAANG companies"; Sliding Window Maximum (239) said to appear "at Amazon and Microsoft". No counts given.
- **Search summary (several prep sites):** fixed-size problems named: Maximum Average Subarray I, Max Consecutive Ones III, Contains Duplicate II; variable: Longest Substring Without Repeating Characters, Minimum Size Subarray Sum, Fruit Into Baskets, Binary Subarrays With Sum; frequency-map: Permutation in String, Find All Anagrams in a String, Minimum Window Substring, Longest Substring with At Most K Distinct (and At Most Two Distinct).
- **Educative patterns blog:** canonical problem Longest Substring Without Repeating Characters; variations Minimum Window Substring and Minimum Size Subarray Sum; a Meta case study of "smallest subarray whose sum exceeded a given number". Sliding window appears "very frequently" in array/string categories, no percentage.
- **InterviewPilot (March 2026):** says only that for Meta "two pointers and sliding window appear very frequently". No per-problem attribution.
- **Local calibration file (2026-10-04):** Meta reports include anagram start indices (438) and a sliding window sum/max for window 3; Netflix reports mention sliding window; X reports array/string.

## Caveats

- All figures are crowd-sourced prep-site claims without stated method. No frequency counts were obtained. Treat as a signal, not data.
- Company attributions for specific problems rest on one or two prep-site articles.
- Problems in the notes that are NOT backed by a curated list or a source above (643, 1456, 219, 340, 904, 1004, 209, 713, 992) are labelled "added for pattern coverage" or "reported in prep-site lists" accordingly. 340 is LeetCode premium.
- Level mapping (3-4 years) is not stated by these sources.
