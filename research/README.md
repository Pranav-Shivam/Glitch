# research/

Local cache of internet research. Check here BEFORE searching the web. Save new research here AFTER searching.

## Rules

1. **Look first.** Read this index and grep this folder for the topic. If a file covers it and is recent enough, use it and say "from local research, retrieved YYYY-MM-DD".
2. **Search only for gaps or stale data.** Interview-frequency and company-process data goes stale (treat anything older than about 6 months as needing a refresh check).
3. **Save after every web research.** One file per topic, named `<area>-<topic>-<year>.md`. Do not overwrite an old file: append a dated "Update" section, or add a new file and note it in the index.
4. **Each file must have:** retrieval date, the question researched, findings, caveats on reliability, and source links. Record what could NOT be fetched (403s, empty pages) so it is not retried blindly.
5. **Keep facts separate from opinion.** Quote or closely paraphrase what a source said. Mark anything inferred as inferred.
